Задача:

Банк отправляет клиенту секретный код для подтверждения операции. Код будет сгенерирован, если только одна из сумм (A или B) в последних двух операциях была четной. Запишите условие генерации кода.


1. Алгоритм решения
1. Начало.
2. Ввод данных: Считать значения сумм двух последних операций (переменные A и B).
3. Проверка условия: Определить, является ли ровно одна из сумм четной.
 • Условие: (A % 2 == 0) != (B % 2 == 0) (или логическое исключающее ИЛИ).
4. Ветвление:
 • Если условие истинно (Да): Сгенерировать секретный код, вывести сообщение «Код сгенерирован» и сам код.
 • Если условие ложно (Нет): Вывести сообщение «Генерация кода невозможна» (так как либо обе суммы четные, либо обе нечетные).
5. Конец.
